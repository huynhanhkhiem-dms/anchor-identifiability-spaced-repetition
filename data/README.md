# Data access

The raw review logs used for the field analysis are **not redistributed in this repository**.

Upstream gated dataset:

- `open-spaced-repetition/anki-revlogs-10k`
- DOI: `10.57967/hf/3435`
- https://huggingface.co/datasets/open-spaced-repetition/anki-revlogs-10k

The upstream license states that the data were provided for memory research and asks users **not to redistribute the data publicly**. Reproduction therefore requires an authenticated Hugging Face account with accepted dataset access conditions.

This repository contains the pinned benchmark commit, code for the frozen analysis, deterministic seed/configuration, and aggregate derived manuscript results. It contains no raw review-level records.
