# Derived results

`field_gate_summary.json` and `field_gate_summary.csv` contain aggregate values reported in the manuscript from the frozen field-gate analysis: 1,000 reduced-information collections and a fixed 150-collection full 21-parameter profile subsample, using seed `20260817`.

These files are derived summaries, not raw user-level data and not a substitute for rerunning the gated source-data pipeline. The complete scripts and notebook are inside `anchor_reproducibility_package.zip`.
